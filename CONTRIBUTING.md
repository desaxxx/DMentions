# Contributing to DMentions

Thank you for helping to improve DMentions!

## Bugs and ideas

Open an [issue](https://github.com/desaxxx/DMentions/issues) with the bug report or feature request template.

## Pull requests

1. **Agree to the [Contributor License Agreement](CLA.md).** Every pull request needs it before it can be merged: tick the box in the pull request description, or comment `I have read the DMentions CLA and I agree to it.` You keep the copyright of your work; the agreement lets the maintainer keep managing the project's license.
2. **Build and test:** `./gradlew build` must pass (it runs the test suite). Java 21 is required.
3. **Commit messages** follow [Conventional Commits](https://www.conventionalcommits.org/): `type(scope): subject`, for example `fix(mention): skip vanished players`.
4. **Keep it focused:** one change per pull request makes it easier to review.
